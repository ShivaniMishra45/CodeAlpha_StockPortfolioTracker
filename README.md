# CodeAlpha Stock Portfolio Tracker 📈

## 📌 Project Overview

This project is a simple Stock Portfolio Tracker developed using Python as part of the CodeAlpha Python Programming Internship.

The program allows users to enter stock names and quantities, calculates the value of each stock, and displays the total investment.

## 🎯 Objective

The main objective of this project is to practice Python dictionaries, user input, arithmetic operations, loops, conditional statements, and basic file handling by creating a simple portfolio tracking application.

## ✨ Features

- Displays a list of available stocks and their prices.
- Allows users to enter multiple stocks.
- Accepts the quantity of each stock.
- Calculates the investment value of each stock.
- Calculates the total portfolio investment.
- Validates invalid stock names.
- Validates invalid quantities.
- Generates a portfolio report in a text file.

## 🛠️ Technologies Used

- Python 3
- VS Code

## 🧠 Python Concepts Used

- Dictionary
- Variables
- User input
- `if-else` statements
- `while` loop
- `for` loop
- Arithmetic operations
- Exception handling
- File handling
